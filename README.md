# NcChallengeApp

A simple Angular application that counts down to an event based on user input. The text size adjusts dynamically based on the content length.

## Prerequisites

- **Node.js** (Install from [nodejs.org](https://nodejs.org/))
- **Angular CLI** (Install via npm: `npm install -g @angular/cli`)

## Setup

1. Clone the repository:

    ```bash
    git clone https://github.com/sarakluge/nc-challenge-app.git
    ```

2. Navigate to the project folder:

    ```bash
    cd nc-challenge-app
    ```

3. Install dependencies:

    ```bash
    npm install
    ```

4. Start the development server:

    ```bash
    ng serve
    ```

5. Open your browser and go to:

    ```bash
    http://localhost:4200
    ```

## Build for Production

To build the app for production:

```bash
ng build --prod
